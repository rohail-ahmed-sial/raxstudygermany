German pronunciation

Every German sound explained with English examples, with a listen button.

German spelling is very regular: learn these rules once and you can read almost any word. Every German sentence on this site has an easy “Say it” line in English letters. CAPITAL letters mark the stressed syllable; ↗ means the voice goes up at the end. Tap any speaker button to hear the word.

Stress – which syllable is strong?

Type of wordRuleExamples
Most German wordsstress the FIRST syllablearbeiten → AR-bai-ten
Abend → AH-bent
leider → LAI-duh
Separable verbsstress the small front partmitbringen → MIT-bring-en
einladen → AIN-lah-den
abholen → AP-hoh-len
be- ge- ver- er- ent-are NEVER stressedbesuchen → buh-ZOO-khen
vergessen → fer-GE-sen
Entschuldigung → ent-SHUL-di-gung
Foreign wordsoften stress the ENDInformation → in-for-ma-TSYOHN
Problem → pro-BLAYM
Büro → bü-ROH

Speaking style – how German sentences sound

WhatHowExample
Statementsvoice goes DOWN at the end ↘Ich komme morgen. → ish KO-muh MOR-gen ↘
Yes / no questionsvoice goes UP at the end ↗Hast du Zeit? → hast doo tsait ↗
W-questions (wann, wo, was …)voice usually goes DOWNWann kommst du? → van komst doo ↘
Crisp endingspronounce every consonant clearly, especially at the endHund → hunt
jetzt → yetst
nicht → nisht
Long vs short vowelsthey can change the meaningStadt (city) → shtat
Staat (state) → shtaht
Temposlow and clear is better than fast – examiners want to understand you

6 typical mistakes to avoid

MistakeSay it correctly
✗ Adding a vowel before sp / st / schStunde → SHTUN-duh (not ishtunde)
Schule → SHOO-luh (not ishkool)
✗ Saying w like English wwir → veer
Woche → VO-khuh
✗ Dropping the final -ebitte → BI-tuh
Grüße → GRÜ-suh
Saying z like English z✗zu → tsoo
zehn → tsayn
✗ Replacing ü / ö with u / o or i / efür → für (not fur)
schön → shön (not shon)
✗ A hard ‘kh’ in ich / nichtich → ish
nicht → nisht
but: Buch → bookh
